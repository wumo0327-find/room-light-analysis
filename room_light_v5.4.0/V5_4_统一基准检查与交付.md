## 已定位的差异

读取的原始记录位于 `D:/桌面/20260920实验数据/建筑光热分析结果/`：

| 原始批次 | 版本 | Ra2 | Cd2 | U0 | 年运行费（元） |
|---|---:|---:|---:|---:|---:|
| 固定挑檐，20260920_100313_930 | 5.1.1 | 0.3059701493 | 0.5776875596 | 0.1082176926 | 455.3346890 |
| 外百叶，20260920_105725_508 | 5.1.1 | 0.3059701493 | 0.5776875596 | 0.1082176926 | 455.3346890 |
| 导光板，20260922_123056_281 | 5.0.0 | 0.2997512438 | 0.5105350107 | 0 | 492.7091419 |

三个基准都是250mm标签、ndiv=20扫描值，未复核。三批的DF均值、照度均值、热不舒适度和空调耗电一致。
每批满负荷照明654.777kWh；空调259.1673966314kWh。

1. **实现差异明确存在。** V5.0.0 `complex_daylight.py` 在每个测点用
   `Dint=ρ×(Ds+Dext)/(1−ρ)`。V5.1.1 改为 `interreflection_field`：
   `Dint=(ρ+ρ²)×B + ρ³/(1−ρ)×平均B`，其中B=Ds+Dext。
   两者的平均通量相同，但后一种会将高阶反射混合到暗区，改变分布、最小值、Cd和Ra。
   同一已有模型在两个历史版本运行，确实出现“平均值一致、V5.0零点、V5.1.1非零”的现象。
   这证明实现差异能导致该现象，**不能据此证明哪一种物理正确**。
2. **费用差异已精确核对。**
   `654.777×(0.5776875595601079−0.5105350106555487)×0.85=37.37445283697元`，
   等于两个年运行费用的差额。费用差异来自旧Cd调光折减，不是COP或空调时长差异。
3. **Ra分母证据。** 两数分别为246/804和241/804，符合相同804个等权有效点的记录。
   没有证据支持“反光板入口删除了零照度点导致分母改变”。
4. **旧几何指纹不充分。** `io_utils/model_audit.py` 将BP墙/窗对象ID加入指纹；
   无嵌入草图的rlproj反向重建会产生新ID。同一个文件重复重建可得到不同指纹。
   所以41D22A95A96B与35C3D59DC24E不能单独证明物理几何不同。原模型仍须比对。
5. **旧导光板批次并非纯外置板。** CSV内伸100～500mm、外挑0～900mm，包含室内或内外组合板。
   V5.2起的EnergyPlus适配器明确不支持室内板的联合光热对象。本次没有将这些状态偷偷当作外置板计算。
6. **旧网格标签的实际含义。** 原 `build_workplane_grid` 用ceil划分跨度后重新均分，实际步长可能小于250mm。
   V5.4实验采用真正250mm网格，并记录实际坐标、数量和裁切面积权重。

## 新实际调用路径

GUI参数化实验 → `StagedExperimentPipeline` → `run_multi_space_experiments` →
三类构件的扫描函数 → 同一 `engine_service.compute_complex_daylight/compute_complex_thermal` →
同一 `calculate_operation_metrics` → 同阶段房间明细与批量汇总 → 重新计算Pareto。

所有实验函数通过 `shared_experiment` 绑定运行配置，并在结束/异常时恢复此前配置。
基准入口是 `run_complex_project_baseline`，其内部使用 `no_device_space` 深拷贝：

## 测点与指标

默认工作面750mm，可在计算设置修改；实验统一250mm，网格从净空间包围盒左下角按半格布点。
每格与净空间多边形（扣除孔洞）相交；权重为实际交集面积。
边界格中心不在净空间时，使用裁切片内部代表点，实际点坐标另行记录，不在墙外进行计算。
全部相交格的面积权重和等于净空间面积。遮挡后0照度仍参与所有统计。

从实际 `_fill_stats` 原公式统一而来，V5.4加权后为：

- `Ra2 = Σ[Ai×I(DFi≥2%)] / ΣAi`，等于2%计为达标。
- `Cd2 = Σ[Ai×clip(DFi/2%, 0, 1)] / ΣAi`。
- `Eavg = ΣAi×Ei / ΣAi`；`DFavg = ΣAi×DFi / ΣAi`。
- `U0 = min(Ei)/Eavg`，平均值为0时U0=0；跨房间也使用全体测点的最小值与面积加权平均。
- `Ei = DFi/100 × Eout`，所以`Eavg=DFavg/100×Eout`。

旧U0=0不是应被删除的坏点：V5.0局部反射模型中，某点Ds与Dext都为0则Dint也为0，最小照度确实为0。
V5.1.1将混合高阶反射引入后，这些点变为正数。V5.4保留零点，不设人为最低照度。
不能仅因换成成熟引擎就保证U0一定大于0，必须核查实际模型和引擎输出。

## 扫描、复核与决策

分级阶段均固定同一250mm测点，只提高反射次数/射线采样：ab3/ad512 → ab4/ad2048 →
ab≥6/ad≥8192 → 必要时ab7/ad16384。若有关键方案未收敛，整个终审关键队列使用同一最后精度。
`scan_*`保留原扫描值；`final_*`保存终审值；`refinement_delta_*=final_*−scan_*`。
基准与房间明细按各自实际阶段重新算，不继承旧CSV或前阶段的相对变化。

收敛规则：Eavg、DFavg相对2%，Ra绝对0.02，Cd绝对0.01，U0绝对0.01，
年度电耗、年运行费、热不舒适度相对3%。记录每项误差、阈值、当前ndiv（Radiance为实际ad）、
前一ndiv与状态；缺少比较值不通过。未经复核的扫描明确标`precision_verified=False`。
数值收敛只证明本实现对该精度加密稳定，不等于物理验证。

重新保存 `within_device_pareto`（构件内部）、`joint_pareto`（三类联合）和现有`global_pareto`。
保持原来的Cd向大、热不舒适度向小、年综合费用向小的三目标，以及成本门槛内光热等权理想点选择规则。
采光/热/费用硬阈值和无节能方案时是否保留基准的现有规则没有替换。正式论文需作者预先确认这些条件，
目前默认Cd≥0.80、Ra≥0.75只是旧程序的试跑阈值；热度时上限、年费用上限默认未设。
