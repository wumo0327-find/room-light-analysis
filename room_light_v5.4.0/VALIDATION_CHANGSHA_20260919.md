# 长沙幼儿园回归核验（2026-09-19）

## 输入

- 工程：`长沙幼儿园.bplan.rlproj`
- 回归副本：`room_light/tests/fixtures/长沙幼儿园_回归基准.rlproj`
- 核验房间：`bp_space_2`（房间2，净面积约51.93 m²，3扇外窗）
- 快速模型：150 mm工作面网格，窗面40×40积分，长沙工程年均室外照度14947 lux。

## 原问题

旧快速模型把室内互反射写成每个点的局部倍率。2370个有效测点中，52个凹窗附近
测点没有直接见窗视线，因而被错算为0 lux，导致 `U₀=Emin/Eavg=0`。

## v5.1.0修正后的150 mm快速筛选结果

| 指标 | 结果 |
|---|---:|
| 平均照度 | 349.864 lux |
| 最低照度 | 37.736 lux |
| 最高照度 | 2856.315 lux |
| U₀ | 0.10786 |
| 平均DF | 2.34070% |
| Ra（DF≥2%） | 0.29325 |

平均照度与平均DF保持不变；修正只重新分配原模型的多次反射光通量。

## Radiance独立对照

为控制单次核验时间，对同一房间使用300 mm网格、5次环境反弹、512环境采样、
室外水平照度10000 lux运行随程序配置的LBNL Radiance：

| 指标 | 快速筛选 | Radiance |
|---|---:|---:|
| 平均照度 | 232.715 lux | 379.414 lux |
| 最低照度 | 25.100 lux | 38.309 lux |
| U₀ | 0.10786 | 0.10097 |

U₀已从不合理的0恢复为与Radiance同量级的非零值。快速模型的绝对照度仍是工程筛选
近似，不得用它替代Radiance定案结果。

## 热环境状态

快速月均模型可运行；房间2当前输入下年均自然室温约24.50℃，月均范围11.15–35.76℃，
热不舒适度49.79℃·月。EnergyPlus IDF已成功生成，但本机未安装EnergyPlus执行引擎，且该工程
的4个房间尚未确认楼面/下部地面热边界。在完成这两项之前，不将逐时热环境称为已完成精度验证。
