# 长沙幼儿园 CAD 转换示例

本目录保存原始 DWG 工作副本、AutoCAD 导出的 DXF、CAD 图层核对图、
清理后的 `.rlproj` 和可重复生成脚本。

## 为什么没有直接把全部 CAD 线条写进工程

原图同时包含多层平面、立面、剖面、尺寸、轴网、家具、洁具、填充、
门扇和天正对象。DXF 中可读取到 2,564 条 `WALL` 直线、271 条墙多段线、
589 条 `WINDOW` 直线和15条窗多段线，但这些图元分布在整张总图上。
直接导入会把其他楼层、立面窗和尺寸辅助线误认为当前楼层墙窗。

本示例采用以下清理规则：

1. 根据首层在 CAD 模型空间中的坐标范围隔离首层平面。
2. 以 `WALL`、`WINDOW` 图层为主，结合图纸44.4m×27.4m尺寸链和房间文字。
3. 删除门扇、家具、楼梯细线、轴网、标注、填充、立面和其他楼层。
4. 将小缝隙吸附到尺寸轴线；墙体中心线必须形成闭合多边形才认定为房间。
5. 每个闭合房间生成独立 `SpaceModel`；几何重合的共享墙记录相邻房间ID。
6. 只保留能稳定归属到房间外边界的外窗，模糊短线不猜测为窗。
7. 保存前通过程序正式几何校验器，任何自交、未闭合或越界窗都会拒绝保存。

## 当前精度用途

该工程适合验证多房间选择、批量采光/热环境和遮阳方案比较。图纸没有提供
完整门窗表与玻璃性能，因此窗台高度、玻璃U值/SHGC和部分局部墙位使用了
可计算的合理初值。正式论文计算前，应根据门窗表、立面图和现场资料复核。

默认选中3个南向活动室。打开工程后可在“建筑视图”中直接点击其他房间
加入或移出计算范围，右键某房间可只选择该房间。普通分析逐房间计算；参数化
实验将同一遮阳方案用于全部已选房间，采光/热指标按面积加权、造价按工程量合计。

本次清理得到34个闭合房间、43扇外窗，总建筑房间面积约849.5m²，保存前通过
闭合、自交、短墙、洞口越界和重叠校验。气象暂沿用益阳TMY近似并标注为长沙，
正式测算应替换为长沙项目所在地的可靠EPW/TMY数据。

## 重新生成

在 `room_light_v3.3.1/room_light` 目录运行：

```powershell
python "examples/长沙幼儿园CAD转换/generate_kindergarten_project.py"
```
