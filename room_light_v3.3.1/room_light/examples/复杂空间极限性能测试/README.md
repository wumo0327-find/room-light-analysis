# 复杂空间极限性能测试

`复杂空间极限性能测试.rlproj` 是为 v3.3.1 复杂空间引擎制作的压力与回归测试工程，不代表真实建筑设计。

模型覆盖：

- 3 层、12 个独立空间；
- 凹多边形、斜墙、锯齿边界、狭长折返、U/L/十字形和近圆形 24 边形；
- 单个及多个内院空洞；
- 外墙、内墙、绝热和接地边界；
- 大量外窗、内门、不同玻璃透光率/U 值/太阳得热系数；
- 全局水平遮阳，以及大量逐窗挑檐和翼板覆盖参数。

默认活动空间为“极限综合测试空间（默认计算）”。它是本工程中计算量最大的空间，用于重点测试采光积分、热环境和参数化遮阳实验。其余空间主要用于检查多楼层、多空间、复杂拓扑、绘图、保存与重新读取。

## 建议的性能测试层级

1. **读写与界面冒烟**：直接打开工程，切换楼层和空间，再保存一份副本。
2. **快速计算冒烟**：采光窗面离散 `ndiv=2~4`，工作面网格 `1500~2000 mm`。
3. **常规压力测试**：`ndiv=8`，工作面网格 `1000 mm`。
4. **极限测试**：使用程序默认精度，并运行多角度、多板长、多间隙、多材料的参数化实验。

极限测试可能耗时很长。建议先记录机器配置、参数组合数、总耗时和峰值内存，再逐级提高精度；不要第一次就直接运行最大的参数网格。

## 重新生成

在 `room_light_v3.3.1/room_light` 目录运行：

```powershell
python "examples/复杂空间极限性能测试/generate_stress_project.py"
```

脚本通过正式的 `save_building_project()` 接口写入工程，保存前会执行所有空间的几何校验。
