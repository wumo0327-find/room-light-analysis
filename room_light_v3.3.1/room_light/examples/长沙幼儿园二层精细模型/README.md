# 长沙幼儿园二层活动室精细模型

本目录用于复核二层三个活动室及其周边空间。程序可直接打开
`长沙幼儿园_二层活动室精细模型.rlproj`，默认选择活动室1、2、3进行批量分析。

## 文件

- `长沙幼儿园二层标注原图.pdf`：用户提供的二层矢量标注图，黄色为墙体、绿色为
  窗、粉色为栏杆。
- `generate_floor2_project.py`：可重复生成工程和预览图的脚本。
- `长沙幼儿园_二层活动室精细模型.rlproj`：v3.3.1 可计算工程。
- `长沙幼儿园_二层活动室精细模型预览.png`：墙、窗、栏杆和默认分析房间的核对图。
- `长沙幼儿园_二层CAD与计算模型对照.png`：左侧为CAD与标注PDF的交叉校核矢量，
  右侧为可计算模型叠加CAD/PDF纠错底图。

生成脚本会先审计原PDF的矢量对象：黄色墙线373条、绿色尺寸线230条、粉色栏杆线
78条、窗线204条，并核对45200 mm总尺寸线、两处2800 mm栏杆和900/2300 mm窗组。
任一数量或关键线宽不一致即停止生成，避免替换图纸后仍沿用旧坐标。

## 本次重建

- 总宽 45200 mm，总进深标注 28200 mm。
- 不再使用矩形活动室和统一“窗面外移1500 mm”的旧近似。
- 三个活动室直接采用DXF中二层 `WALL` 内边线坐标生成非矩形闭合多边形，
  南侧凹凸墙、200 mm窗间构造和端部折返均进入计算边界。
- 活动室1为左900窗和中2300窗深退、右900窗浅退；活动室2、3为两侧
  900窗浅退、中间2300窗深退。
- CAD/PDF中的门只用于理解原图关系；本测试模型按用户要求不保留任何门洞，
  原门位置全部封闭为连续墙体，包括活动室3北侧原3680 mm开口。
- 每个活动室的三组窗均直接附着在对应折线墙段上，不再依赖
  `plane_offset_mm` 模拟造型。
- 不再只建两处2800 mm南侧栏杆。PDF中的两侧阳台、内院四周、音体活动室旁、
  东西楼梯扶手以及门厅上空边缘均已补为世界坐标遮挡层；双线/三线栏杆合并为
  单一计算中心线，避免同一栏杆重复衰减。
- PDF的黄色墙、灰绿色窗、粉色栏杆/雨棚边界和青色玻璃雨棚全部保存到
  `storey.metadata.pdf_reference`。它与`cad_reference`相互独立，CAD损坏或
  图层缺失时仍可追溯并补全空间。
- 活动室北侧盥洗/卫生/衣帽带进深 2400 mm，公共走廊进深 1900 mm。
- 工程共保存26个可选空间；寝室、盥洗卫生/衣帽带、公共走廊、音体活动室及
  北侧办公/卫生空间均保留，内院上空和门厅上空不伪装成房间。
- 原CAD二层范围内的 `WALL/WINDOW/COLUMN` 路径完整写入
  `storey.metadata.cad_reference`，保留原图毫米坐标和转换原点，便于后续
  建筑视图逐线显示及再次审计。

## 程序为此图升级的能力

活动室窗现在直接位于CAD真实退进墙段上，采光射线使用实际折线边界与窗坐标；
`WallOpening.plane_offset_mm` 只继续用于图中仍以规则房间近似的相邻寝室窗。

`ExteriorBarrier` 可保存实体墙、栏杆、女儿墙或屏风，并区分其位于玻璃外侧、测点
与玻璃之间或整条射线路径。实体墙完全遮挡，栏杆按有效开敞率部分衰减。建筑视图
会将实际窗面画在外移位置并用连接虚线提示；栏杆显示为粉色，实体返回墙显示为
黄色/棕色。

本工程把去重后的栏杆中心线附到每个可选房间的同一世界坐标遮挡层中。采光射线只在
真实相交时才衰减，因此不会因为房间不同而漏掉同一处室外栏杆。任意栏杆对月度热工
太阳得热的逐时投影尚未由当前热模型求解；相关几何已作为
`thermal_solar_obstruction_reference`保存，不能把“已识别”误写成“已完成热工精算”。
玻璃雨棚为水平构件，现阶段同样完整保存平面矢量，但在取得标高、厚度和玻璃光热
参数前不强行按竖直屏障计算。

## 尚需立面或门窗表复核

本张平面图不能证明窗台高、窗高、玻璃型号、栏杆高度和栏杆真实光学开敞率。当前
占位值为：

- 窗台 600 mm，窗高 2400 mm；
- 普通中空玻璃，可见光透射比 0.70，SC 0.55；
- 栏杆高 1100 mm，有效开敞率 0.65。

这些值在工程元数据中均标记为 `assumed_pending_schedule/elevation`，没有伪装成
已确认尺寸。用于论文最终数据前，应根据二层立面、门窗表或现场测量替换。

## 建模边界

三个活动室的折线边界和南窗位置已按CAD/PDF交叉重建，原门洞已封墙，是本文件
当前最可靠的计算区。相邻寝室、服务房间和北侧房间保留为独立可选空间；这些非
活动室空间仍以清理后的规则计算边界表示，但原CAD墙窗柱路径和PDF纠错矢量均已
完整保存在工程元数据中，不会丢失。门扇开启弧已被墙替代；家具、洁具、尺寸和文字
不参与物理计算。
