# RoomLight 论文级验证规程（v4.4.0）

本文件区分“程序内部一致”与“物理结果已经得到独立验证”。前者是运行计算的最低条件，后者才足以支撑论文中的绝对精度结论。

## 1. 几何一致性（运行前强制）

- BP 原始草图作为墙、窗、栏杆和接头显示的唯一来源；建筑视图直接读取当前草图对象或 `.bplan.json`，不经 `.rlproj` 中间文件重建显示。
- RL 保存墙/窗宿主轴线，并另外保存实体墙内表面净空间。
- 每次分析前核对：墙体尺寸有限且为正、窗户未越出宿主墙、房间闭合且不自交、BP/RL 房间数量一致、BP 窗与 RL 唯一窗一一映射。
- BP 孤立墙不得静默忽略：未形成房间边界的墙必须删除、补全围合，或明确改画为栏杆/采光遮挡构件，否则阻止计算。
- 生成模型指纹；结果 CSV 和“模型与计算溯源.txt”必须记录同一指纹。
- 任一错误均禁止开始计算。旧复杂空间工程若缺少净空间，必须在 BP 中重新应用后才能用于论文计算。
- 新建/重新应用的 BP 房间必须逐批确认上方屋面和下部地面热边界；未确认时禁止采光+热环境批量分析和参数化实验，防止二层房间被默认算成顶层兼首层。

## 2. 数值收敛（参数化实验自动执行）

- 全部方案先以 `ndiv=20` 扫描。
- 三张二维帕累托、三目标全局帕累托以及综合推荐前8名，按 `ndiv=40 → 60 → 80` 自适应复核；相邻两级达到阈值即停止。
- 暂定采光收敛阈值：`|ΔRa| ≤ 0.005`、`|ΔU0| ≤ 0.01`。月均热模型不依赖窗面离散数，因此不随 `ndiv` 重算；热模型的物理精度由第4节独立校核。
- 未收敛或超过复核数量上限的关键方案必须在缩小参数范围后重算，不能直接作为论文定案。
- CSV 同时保存扫描值、复核值、差值、积分密度和收敛状态，不以图上红圈代替数据证据。

## 3. 可行域、最小干预与帕累托（可复算）

- Cd、Ra、U0、热不舒适度和年综合费用硬约束必须在查看结果前登记；0表示关闭，默认试跑阈值不等于规范自动限值。
- 每个方案输出逐项归一化违反度、最大违反度、主导瓶颈和残余补偿缺口。离散域无解时只能写“在本研究参数域内未发现可行解”。
- 按 L0→L1→L2→L3 搜索，较低层级出现可行解即停止；L2必须按联合几何重算，禁止把两个L1指标直接相加。
- 采光×热：只使用 `Cd` 与热指标；Ra、U0作为独立约束/报告指标保留。
- 采光×造价：只使用 `Cd` 与造价。
- 热×造价：只使用热指标与造价。
- 3D 全局前沿：同时使用 `Cd↑`、`热不舒适度↓`、`年综合费用↓`。
- 所有材料与几何进入同一候选池，不给任何材料预留名额；数值等价的不同材料全部保留。
- 金色推荐方案采用最低可行干预层级及预登记的层级内最小口径；二维/三维帕累托只用于解释权衡边界。

## 4. 独立软件与实测验证（论文发表前必须补做）

1. 从低复杂度矩形房间开始，建立 RoomLight、Radiance/Honeybee 和 EnergyPlus 的同几何、同材料、同气象对照模型。
2. 逐级增加角窗、凹窗、回廊栏杆、凹多边形和多房间，记录每级误差来源。
3. 采光至少比较测点照度/采光系数、平均值、U0 和 Ra；热环境至少比较逐月室温、太阳得热与不舒适度。
4. 使用真实教室测点做最终校准，报告 MBE、MAE、RMSE、CV(RMSE)，并保留原始测量条件。
5. 对湖南材料单价、支撑和安装费做低/中/高三档敏感性分析，避免单一市场价决定帕累托结论。
6. 百叶至少用 Radiance 对照片宽、间距、角度和室内/中空/室外位置；固定与季节控制分别验证，不把月代表控制写成逐时自动控制。
7. 反光板至少核对近窗过亮、深部照度增益、U0、上窗比例和内外板倾角；热侧用EnergyPlus核对外板遮阳与内板得热，不能只验证平均照度。

当前 v4.4.0 已完成几何/参数扫描/判定链的内部验证框架；独立逐时模型和实测仍未由程序自动完成，不得把“内部测试通过”表述成“已经证明物理精度”。
