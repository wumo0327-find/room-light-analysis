```bash
pip install -r requirements.txt

```

## 操作步骤

### 1. 输入房间参数
侧边栏「房间几何」：设置长/宽/高（mm）。

### 2. 添加窗户
侧边栏「窗户」→ 选择朝向 → 「+ 添加窗户」→ 展开卡片设置坐标、尺寸、透射比。  
坐标系：以该朝向墙面左下角为原点，X=距左边(mm)，Y=距底边(mm)。

### 3. 设置材料参数
「材料反射率」：墙/顶/地/室外地面反射率（光学参数，用于采光计算）。

### 4. 设置热工参数（v2.2新增）
「围护结构热工参数」：传热系数 U（W/m²K）、遮阳系数 SC、外墙吸收系数、换气次数、内热扰密度等。

### 5. 设置气象数据
侧边栏「气象数据」→「⚙ 更改气象数据…」，弹窗支持：
- **手动输入**：逐月填写照度(lux)和温度(℃)，可一键填入益阳/北京 TMY 参考值
- **导入文件**：.xlsx/.csv，格式：列A=月份，列B=照度，列C=温度

### 6. 全部分析
工具栏「▶ 全部分析」，弹出进度条窗口，实时显示：
- 采光分析（逐行进度）
- 热环境分析（逐月进度）  
支持**暂停**和**取消**。

### 7. 查看结果
- **建筑视图**：平面图 / 南北东西立面图（含窗户标注）
- **采光分析**：照度热力图 + KPI（Eavg/U₀/DF/WFR）+ 截面分布图
- **热环境**：逐月室温折线图 + 舒适判定 + 热流分解

### 8. 导出结果
工具栏「↓ 导出结果」，勾选需要导出的内容：
- 采光热力图 PNG
- 截面分布图 PNG
- 热环境分析图 PNG
- 光热综合对比图（拼合）PNG
- Excel 报告（含所有数据）

统一设置保存路径和文件名前缀，一次批量导出。

## 项目文件（.rlproj）

格式：JSON，包含全部房间参数和气象数据。

**保存：** 工具栏「💾 保存」（首次弹路径选择，后续直接覆盖）/ 「另存为」  
**打开：** 工具栏「📂 打开」或将 .rlproj 文件**直接拖入程序窗口**  
**向后兼容：** 支持读取所有历史版本（v0.1 ~ v2.2）的 .rlproj 文件，缺失字段自动使用默认值。

**用房间 411 / 509 两间真实教室实测数据跑通 `validate_daylight.py` 全流程验证**（几何、水平挑檐850mm+垂直翼板850mm、材料反射率、玻璃 Tvis 均按用户提供的实测/假设值配置，见 `examples/validate_411_509/`）：
- 四条测线（2 房间 × 沿窗中线/沿窗间墙中线）整体 MAE=1.47（DF%），MRE=141.0%，**远超 50% 的合理性阈值，判定为异常，未通过验证**，不作为最终可信结果，需下一步排查后重跑：
  1. **反射率假设推高 ρ̄ 越过 BRS 互反射公式的有效范围**：给定的顶棚/墙/地反射率(0.80/0.70/0.35)使 ρ̄=0.627，超过代码注释里 BRS 公式本身标注的有效范围 ρ̄<0.6；灵敏度测试显示改用更保守的典型反射率（ρ̄≈0.47）可使窗中线 MRE 从 54% 降到 19%，是系统性偏高（本次 20 个点全部模拟值 > 实测值）的主要来源之一。
  2. **垂直翼板对"窗间墙测线"的差异化遮挡明显不足**：无论是否加遮阳，模拟的"窗间墙/窗中线"DF 比值始终在 0.9~1.0（两测线几乎同亮），而实测比值稳定在 0.51~0.66（窗间墙测点明显更暗）。诊断为翼板的镜像对称几何判定只能有效遮挡"该窗自身的临边斜视线"，对窗间墙测点看相邻两窗的斜视线覆盖不足（该测点与翼板几乎同一沿墙坐标，射线在到达翼板出挑区之前已在窗洞面处终止，t 参数达不到判定所需的 t≥1），需要重新设计窗间墙测点的遮挡建模（而非照搬水平挑檐的镜像数学）才能吻合实测的强差异化。
- 输出物：`examples/validate_411_509/`（两间房 `.rlproj`、两份实测 CSV、两份结果 CSV、两张单图叠加对比 PNG，`--plot-mode combined` 新增，两测线同图不同色，实测散点+程序曲线）。

- **采光遮挡（`core/daylight.py`）**：`_ds_point` 天空分量积分新增水平挑檐几何可见性判定，被挑檐遮挡的天空面元从积分中剔除，自动联动 DF/E_avg/U0/Ra。出挑深度=0 与无遮阳结果逐位一致。
- **热工遮阳（`core/thermal.py`）**：`SC_effective` 由恒定标量改为**逐月序列**——按逐月太阳剖面角求挑檐遮挡高度比例 f（连续插值，非二值），有效 SC = SC_glass·(1−f·(1−k_diff))。新增 `SC_effective_monthly[12]`。
- **`ShadingDevice`**：新增 `diffuse_residual`（完全遮挡残余透过比 k_diff，默认0.30，可配置）与 `beam_shade_fraction()`；`.rlproj` 同步序列化并向后兼容。
- **新增指标 Ra（采光达标面积比）**：`compute(..., ra_threshold=2.0)`，阈值可配置；`DaylightResult.Ra`。
- **参数化实验框架（`core/experiments.py` + `run_experiments.py`，新增）**：无 GUI 命令行入口，玻璃材质对照组 + 遮阳β扫描主实验组，结果汇总为 pandas 表；2D 帕累托前沿提取 + 散点气泡图（白底学术主题，成本→气泡大小，组别→marker，不合规点灰显，前沿高亮连线）。新增 pandas 依赖。

**修正（bug fix）：**
- **外墙 sol-air 太阳附加得热高估约 20×**：旧公式 `α·I·A/R_ext` 把外墙吸热几乎全部计入室内，导致室温虚高（年均42℃/峰值66℃）、遮阳对舒适性失效。改为标准 sol-air 向内传热 `U_wall·A·α·I_vert/h_out`，室温回到合理区间（年均~22℃/峰值~35℃），遮阳得以真正影响热环境。

**已知局限（论文需说明）：**
- 「月中日正午」代表工况下，东/西向窗正午几乎无直射，挑檐对其月度遮阳无效（本项目窗以南向为主）。
- 离散舒适月数在炎热气候下易饱和，主实验帕累托建议用连续量（Σ超温度·月 / 热不舒适度）作热轴。
- 侧窗深房间 U0 本就偏低（<0.70），合规筛选阈值 `--u0-min` 可配置。
- Dext 尚未计挑檐下表面反射补光（代码留 TODO，阶段二实现）；百叶/导光板仍为预留。
