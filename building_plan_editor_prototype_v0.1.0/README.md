# 建筑平面绘图原型 v0.1.0

这是独立于 RoomLight 的空间编辑原型。当前阶段只验证建筑平面绘图、墙窗栏杆关系
和闭合房间识别，**不会修改或覆盖任何 `room_light_v*` 文件夹**。交互稳定后再将
数据模型与画布迁入 RoomLight。

## 启动

```powershell
cd building_plan_editor_prototype_v0.1.0
pip install -r requirements.txt
python main.py
```

可通过“打开”载入 `demo_activity_plan.bplan.json` 查看带凹凸交接墙、窗和阳台栏杆
的演示图。

## 天正式操作逻辑

### HZQT：绘制墙体

1. 点击“H Z Q T 绘制墙体”，或在底部命令框输入 `HZQT`。
2. 悬浮参数窗设置墙高、墙宽、轴线居中/靠左/靠右，无需点确认。
3. 直接回到图面左键指定起点；第一次点击自动采用当前参数。悬浮窗可随时修改，下一段立即使用新值。
4. 指定起点并移动鼠标确定方向后，可在命令框输入准确长度并回车。
5. 右键或 `Esc` 结束；`F8` 切换正交绘制。

墙体采用灰白填充、灰色边线，中心虚线为绘制轴线。轴线接通的直线续段、
L形、T形和交叉墙会按每段真实的居中/靠左/靠右偏移求实体边线交点，再按整体
并集绘制；不会用统一的半墙宽延伸造成墙头外露。共线、同厚、同高且实体侧向
一致的连续墙段，在中间没有T形/十字支墙时会自动合并成一整堵墙；出现支墙时
自动拆分，支墙删除或移走后又会恢复合并。合并过程会保留墙上窗的实际位置。

### MC：绘制窗体

1. 点击“MC 绘制窗体”，或输入 `MC`。
2. 悬浮参数窗设置窗台高、窗户高度和窗宽，修改值实时更新图面预览。
3. 鼠标靠近墙体后自动吸附到最近墙，蓝色预览实时显示窗宽、左净距和右净距。
4. 左键按当前鼠标位置插入；也可以直接输入“窗左边缘距墙起点”的数值并回车。

窗必须依附墙体，越界或与同墙已有窗重叠时拒绝创建。
窗体采用浅蓝色表示。

### LG：绘制栏杆

1. 点击“LG 栏杆”，或输入 `LG`。
2. 在悬浮参数窗设置栏杆高度、材料和绘图宽度。
3. 与墙体相同，连续点击绘制，也可输入精确长度。

栏杆采用灰色，轴线相接的栏杆会像墙体一样自动连续过渡。栏杆作为独立图元
保存，不会被误认为实体墙。

### L：绘制普通直线

1. 输入 `L` 或点击“L 直线”。
2. 指定起点、终点，可连续绘制；也可先指定方向再输入准确长度。
3. `Enter`、空格或右键结束。

普通直线是独立辅助图元，可选择、移动、复制、镜像、删除和保存，但不参与墙体
并集、房间围合或热工边界判断。

### M / CO / MI：移动、复制和镜像

- 可以先选择图元再输入命令；也可以先输入命令，再点选/框选图元，按
  `Enter`或空格确认选择。
- `M`：指定基点和目标点，按两点位移移动图元。
- `CO`：指定基点后可连续指定多个目标点；`Enter`、空格或右键结束。
- `MI`：指定镜像轴第一点和第二点，默认保留原图元并生成镜像副本。
- 移动墙体时，墙上的窗保持原有轴线偏移并随墙移动；复制或镜像墙体时，宿主窗
  自动随墙复制。单独移动或复制窗体时只能沿宿主墙轴线移动，避免产生悬空窗。

### ZDBZ：逐点尺寸标注

1. 点击“ZDBZ 逐点标注”，或输入 `ZDBZ`。
2. 第一点指定尺寸起点。
3. 第二点指定第一个测量终点。
4. 第三点指定尺寸线的标注位置，基础尺寸立即生成。
5. 后续每次点击继续追加新的测量点。
6. `Enter`、空格或右键完成命令，`Esc`取消当前命令。

尺寸链会随BP文件保存，支持选择、框选、删除和撤销。

## 其他操作

- 鼠标滚轮：缩放。
- 鼠标中键拖动：平移。
- 左键点选图元；按住 `Shift` 或 `Ctrl` 可逐个切换选择状态。
- 双击墙体、窗体或栏杆，会打开与创建时相同的参数窗并载入该构件当前参数；
  修改墙高/墙宽/轴线、窗台高/窗高/窗宽或栏杆高度/宽度/材料后立即更新图面。
  参数不合法（例如窗宽越过宿主墙或与其他窗重叠）时会拒绝修改并恢复原值。
- 单选、Shift/Ctrl切选或框选一个或多个图元后，按 `Ctrl+1` 打开“特性”窗口。
  窗口按图元分别列出墙、窗、栏杆、普通直线和尺寸标注的几何与构造参数；
  特性窗口保持打开时，继续改变选择集会自动同步刷新。
- 选中墙体后，轴线两端出现蓝色夹点；直接拖动夹点即可重新调整墙体长短。
  带窗墙体限定沿原轴线拉伸，避免窗体脱离宿主墙。
- 在空白处拖框：左向右为“完全包含才选中”，右向左为“相交即选中”。
- `Delete` 批量删除当前选择。
- `Ctrl+Z`：撤销，最多100步。
- `F`：范围显示全部图元。
- 自动索点适用于绘墙、绘栏杆、绘直线、逐点标注以及移动/复制/镜像的基点和
  目标点。当前支持：
  - 端点：绿色方框；
  - 中点：绿色三角形；
  - 两条有限轴线的真实交点：绿色叉号；
  - 已指定起点到墙、栏杆或直线轴线的垂足：绿色直角符号；
  - 轴线上的最近点：绿色菱形。
  特殊点在13像素捕捉范围内优先，最近点使用更小的9像素范围，避免抢走端点、
  中点、交点或垂足。未捕捉到构件时继续使用原有栅格和F8正交。
- 支持保存/打开 `.bplan.json`、导出当前画布PNG，以及把闭合房间导出为
  RoomLight `.rlproj`。
- 无需点击命令框：画布、工具栏或普通界面控件具有焦点时，可直接键入
  `HZQT`、`MC`、`LG`、`L`、`ZDBZ`、`M`、`CO`、`MI`或数值；字符会
  自动进入底部命令框。
- `Enter`用于执行命令或结束正在运行的命令；空格除具备相同作用外，在没有
  活动命令且命令栏为空时，会重复执行上一个有效命令。
- `Esc`取消当前命令并清除当前选择；没有活动命令时也可单独用于取消选中。
- 切换到其他命令、视图或文件操作时，原命令的悬浮参数窗自动关闭。
- 参数上下箭头按建筑模数调整：主要高度和窗宽为100 mm步进，墙厚及栏杆绘图
  宽度为10 mm步进。

## RoomLight工程与视图切换

- “打开”可以直接读取 `.rlproj`。
- 兼容旧版单矩形房间工程，以及3.x楼层—空间—边界墙结构。
- 导入复杂工程时，当前读取第一楼层；多个空间共用的同一物理墙会自动去重，
  反向存储的墙上窗会换算回正确位置。
- 可识别 `.rlproj` 中的栏杆类外部障碍。
- `.rlproj` 作为来源文件只读导入；编辑后的内容另存为 `.bplan.json`，不会覆盖
  原RoomLight工程。
- 顶部“导出rlproj”会把当前图纸转换为RoomLight 3.3建筑工程：每个自动识别的
  闭合房间成为一个可独立计算的空间；两个房间共用的边界成为带相邻空间关系的
  内墙；窗体重新挂接到对应边界墙；栏杆作为采光射线障碍导出。普通直线和尺寸
  标注只随工程元数据保存，不参与采光或热环境计算。
- 没有闭合房间时拒绝导出，避免生成外观正常但无法计算的工程。导出后程序会
  报告空间、边界墙、窗和栏杆数量。
- BP暂未编辑玻璃光热性能、墙体构造和逐月气象；导出的工程采用RoomLight默认
  构造参数，位置暂设为湖南益阳且不写入逐月气象。正式计算前必须在RoomLight中
  按真实项目复核气候、玻璃和热工参数。
- 顶部视图框可切换平面图、北/南/东/西立面。立面按墙高、窗台高、窗高和栏杆
  高度生成，并严格按观察方向由远到近绘制：例如北立面中，靠北墙体会遮挡其
  投影范围内的南侧墙体、窗体和栏杆。
- 立面投影使用墙体的实体宽度，而不仅是轴线。北/南朝向墙体从东、西立面观察
  时属于端面投影：先参与前后遮挡，只有端面没有被更近墙面覆盖时才显示墙厚；
  东/西朝向墙体从北、南立面观察时同理。相连墙面会按转角宽度延伸遮挡范围，
  不会在正面立面中错误露出半个墙厚的窄边。

## 自动识别房间

程序不要求输入房间名。每次墙体变化后，会：

1. 将墙轴线在端点、T形交点和十字交点处自动拆分，并把拆分结果写成可独立
   选择、删除的真实墙段；若交点落在窗洞内部则不强行拆开宿主墙；
2. 建立平面墙体拓扑图；
3. 排除未闭合边界和建筑外部无限面；
4. 将剩余闭合面识别为房间，并用淡色底纹显示。

因此规则矩形、凹凸墙、共享隔墙、T形分隔和十字分隔均可识别。栏杆不参与房间
围合，避免把阳台栏杆错误当成实体房间边界。对于轴线靠左/靠右的墙体，识别
前还会检查两段实体墙带是否真实搭接：即使轴线端点因墙厚偏移而没有重合，只要
实体墙已经形成有效转角，也会按真实轴线交点闭合；实体墙之间确有缝隙时则仍然
判定为未闭合。

## 当前边界

这是第一阶段绘图原型，尚未迁入 RoomLight，也没有实现门、柱、圆弧墙、轴网和
天正DWG对象兼容。立面目前是根据二维墙段及其高度生成的几何核对视图，不是完整
建筑立面排布引擎；多楼层 `.rlproj` 当前只导入第一楼层。
