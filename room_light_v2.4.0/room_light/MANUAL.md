# 使用手册 & 版本更新日志

## 安装与启动

```bash
pip install -r requirements.txt
python main.py
```

**依赖：** Python 3.10+，PyQt6，matplotlib，numpy，openpyxl

## 操作步骤

### 1. 输入房间参数
侧边栏「房间几何」：设置长/宽/高（mm）。

### 2. 添加窗户
侧边栏「窗户」→ 选择朝向 → 「+ 添加窗户」→ 展开卡片设置坐标、尺寸、透射比。  
坐标系：以该朝向墙面左下角为原点，X=距左边(mm)，Y=距底边(mm)。

### 3. 设置材料参数
「材料反射率」：墙/顶/地/室外地面反射率（光学参数，用于采光计算）。

### 4. 设置热工参数（v2.2新增）
「围护结构热工参数」：传热系数 U（W/m²K）、遮阳系数 SC、外墙吸收系数、换气次数、内热扰密度等。

### 5. 设置气象数据
侧边栏「气象数据」→「⚙ 更改气象数据…」，弹窗支持：
- **手动输入**：逐月填写照度(lux)和温度(℃)，可一键填入益阳/北京 TMY 参考值
- **导入文件**：.xlsx/.csv，格式：列A=月份，列B=照度，列C=温度

### 6. 全部分析
工具栏「▶ 全部分析」，弹出进度条窗口，实时显示：
- 采光分析（逐行进度）
- 热环境分析（逐月进度）  
支持**暂停**和**取消**。

### 7. 查看结果
- **建筑视图**：平面图 / 南北东西立面图（含窗户标注）
- **采光分析**：照度热力图 + KPI（Eavg/U₀/DF/WFR）+ 截面分布图
- **热环境**：逐月室温折线图 + 舒适判定 + 热流分解

### 8. 导出结果
工具栏「↓ 导出结果」，勾选需要导出的内容：
- 采光热力图 PNG
- 截面分布图 PNG
- 热环境分析图 PNG
- 光热综合对比图（拼合）PNG
- Excel 报告（含所有数据）

统一设置保存路径和文件名前缀，一次批量导出。

## 项目文件（.rlproj）

格式：JSON，包含全部房间参数和气象数据。

**保存：** 工具栏「💾 保存」（首次弹路径选择，后续直接覆盖）/ 「另存为」  
**打开：** 工具栏「📂 打开」或将 .rlproj 文件**直接拖入程序窗口**  
**向后兼容：** 支持读取所有历史版本（v0.1 ~ v2.2）的 .rlproj 文件，缺失字段自动使用默认值。

## 快捷操作

| 操作 | 方式 |
|------|------|
| 修改参数实时预览 | SpinBox 直接输入，120ms 后画布自动刷新 |
| 调整数值 | 点击选中 SpinBox 后使用方向键；**滚轮不调数值**（防止误触） |
| 切换视图 | 工具栏视图按钮 / 分析完成后自动跳转 |
| 打开项目 | 工具栏按钮 / 拖拽 .rlproj 到窗口 |

| 参数 | 数值 |
|------|------|
| 纬度 | 28.59°N |

| 气候区 | 夏热冬冷（GB 50176-2016）|

| 年均气温 | 18.4℃ |
| 数据来源 | CSWD / 中国气象局标准气象年 (TMY) |

## 版本更新日志

### v2.4.0（当前）
**新增：**
- 热环境分析模块（`core/thermal.py`）：单区集总热平衡，月均自然室温，超温/欠温/舒适月数评判
- 热分析结果面板（`ui/thermal_panel.py`）：逐月室温折线图 + 热流分解条形图 + 舒适状态色块
- 围护结构热工参数侧边栏面板：U值、SC、吸收系数、换气次数、内热扰密度、热桥修正
- 全局分析进度条对话框（`ui/progress_dialog.py`）：实时逐行进度、暂停、取消
- 勾选式导出对话框（`ui/export_dialog.py`）：支持各模块图片 + 光热综合拼合图 + Excel 批量导出
- WeatherDataset 新增 `monthly_temp[12]`（月均室外干球温度），气象数据弹窗新增温度列
- .rlproj 格式升级：新增 thermal、shading 字段；**向后兼容所有历史版本**，旧文件缺失字段自动填默认值
- ShadingDevice 数据类预留接口（v2.3 实现遮阳构件精算）
- 文档拆分：THEORY.md（计算理论）+ MANUAL.md（本文件）

**优化：**
- 采光计算新增 `row_cb` 逐行进度回调，配合进度条实时更新
- 热环境计算灵敏度：U_wall 1.5→0.6，年均室温差 −6.3℃；SC 0.85→0.42，年均差 −0.45℃
